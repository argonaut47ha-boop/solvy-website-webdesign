# Steady Local website

Static site, no build step. Open `index.html` or serve the folder (`python3 -m http.server`).

Before launch, replace: brand name, contact info, `FORM_ENDPOINT` in `assets/site.js`, and the schema URL in `index.html`.

Pages: `index.html`, `audit.html`, `terms.html` (draft, have an attorney review).
Layout ideas inspired by 21st.dev previews (hero with chat demo, glass stats, highlighted middle pricing tier); no third-party code is used.
